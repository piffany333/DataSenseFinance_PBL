> PBL Portfolio Project - DataSense Finance

**Student:** piffany333
**Repository:** https://github.com/piffany333/DataSenseFinance_PBL

### 1. Project Overview
This project aims to forecast daily cash demand per bank branch to optimize ATM refilling and reduce idle cash. Part of DataSense Finance PBL.

### 2. Problem Statement
Banks lose money with over-stocked branches (idle cash) and under-stocked branches (customer dissatisfaction). Goal is to predict `Cash_Withdrawal_Amount` accurately.

### 3. Tech Stack
- Python, Pandas, NumPy
- Matplotlib / Seaborn for EDA
- Scikit-learn (RandomForest, XGBoost)
- Jupyter Notebook
